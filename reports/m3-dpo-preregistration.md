的 28,842 行偏好数据上做 1 epoch DPO，判据是**行为学门禁必须在同一台仪器上守住起点水位**。

## 5. 训练期监视（DPO 的失效模式与 SFT 不同）

DPO 的典型崩塌**不是** loss 上升，而是 **`rewards/accuracies` 冲高到 ~1.0 同时
`rewards/margins` 无界增大**——即模型退化为"对 rejected 一律给极低概率"的**空心拒答**
（C 路已实证：93–95% 的"攻击成功"根本没有裁决行）。故看门狗监视：

1. `rewards/accuracies`：健康区间约 **0.55–0.85**；若 ≥0.97 且维持 → **预警**（可能坍缩为空心拒答）。
2. `rewards/margins`：单调无界增长是过拟合约信号。
3. ~~`logps/chosen` 与 `logps/rejected`~~ → ★**改用 `rewards/chosen` 与 `rewards/rejected`**。
   **口径更正（2026-09-30，第一位看门狗实证）**：`logps/*` 是**整条回复的绝对 log 概率和**，
   同时含（a）长度依赖、（b）每个 logging 点的随机 batch 平均不同 ⇒ **不可用作跨步比较**。
   实测反例：step 200 的 `rewards/chosen = +4.02`（比冻结参考高约 40 nats），
   而同一步的 `logps/chosen` 比 step 5 **低 84 nats**——两者符号相反，用 `logps/*` 会得出反向结论。
   `rewards/*` **已逐样本减掉参考模型**，是唯一可用于"抬 chosen / 压 rejected"判断的量。
   核心观测量：**rejected 侧的下降幅度**——若 rejected 崩塌而 chosen 几乎不动
   ⇒ 学的是"抑制"而不是"偏好"。
4. `loss`：DPO loss 不一定下降（sigmoid DPO 在 margin 增大时 loss 反而升），
   因此 **loss 不作判据**，只作异常绊线（NaN/Inf/长时间不动）。
5. 显存/步时：**VRAM + 主机 commit 是本机最薄的资源**（docs/01 §11.7）；
   若步时连续 3 次以上升 >50% 且功率掉到 <200 W ⇒ 判为 WDDM 分页，报我。
6. **中断可无损续跑**：`save_steps 100` ⇒ 任何终止最多损失 99 步。

**早停规则（保守，且必须报告而非自作主张）**：只有 `rewards/accuracies ≥ 0.97` 连续 5 个
logging 点 **且** `rewards/margins` 同期翻倍以上 ⇒ 判为"疑似空心化"，**停下并报告**，
由我按 §4 判据用就近 checkpoint 做行为学门禁后决定。**不得**因 loss 波动自行终止。

## 6. 可否证性

1. 若 M3 后未见载体 ASR 显著劣于 7/168 ⇒ **载体多样性批次（20.8%）未能保护主轴**，
   则"数据组成可护住泛化"的假设被否证，须回到"顺序重排"（把对齐放到加法之前/之后）方案。
2. 若 M3 后 ASR 不劣化且契约 ≥63 ⇒ **首次证明"对齐可以不牺牲使命主轴"**，
   这是本项目最关键的正向结论（此前每一轮训练都在侵蚀该轴）。
3. 若 `rewards/accuracies` 冲顶且行为门禁显示大量无 VERDICT 的"成功" ⇒ 复现 C 路空心化，
   说明 DPO 在本体上会优先走"抑制"路径。

## 7. 纪律

- GPU **严格串行**（并发实测 10× 退化）；任何 GPU 作业前先确认 `memory.used` 与无 python 进程。
- 训练中**并行只做 CPU 侧**（数据/文档/复算），不碰 GPU。
- 每个中间档（每 100 步）都是可续跑资产；看门狗日志独立于主日志。
- 产物落盘后**先跑行为学门禁再宣布任何结论**；`eval_loss` 一律不作判据。

**D3｜训练期监视口径的更正 + "早停规则原理上检测不到抑制主导"（父代理据看门狗报告登记）**

- **事实（看门狗独立复算，step 205→300 窗口）**：`rewards/chosen` 斜率 **+0.40/100 步（r²=0.02，等于平的）**，
  水平仅 **+0.74**（≈冻结参考）；`rewards/rejected` 斜率却再下压，水平 **−8.96**（前段均值 −3.88 的 **2.3×**）。
  全窗口 **Δrejected/Δchosen = 9.11/0.28 = 33×** ⇒ 本 run 学到的**主要是抑制，不是偏好**。
- **原理性缺陷（本条是本次最重要的方法论收获）**：§5 的早停规则是
  「`acc≥0.97` 连续 5 点 **且** `margins` 翻倍」的**合取**。
  但 `margins = rewards/chosen − rewards/rejected` ⇒ **只要 rejected 持续下压，margins 就机械满足"翻倍"**
  （实测 248×，远超阈值），**它对该组成特征完全不敏感**。两个条件里**只有 acc 条有判别力**，
  而 acc 也是合成分。**⇒ 这套绊线在原理上只能抓"整体过度自信"，抓不到"抑制主导/空心化"。**
- **处置（刻意不干预）**：早停**未触发**（acc≥0.97 最长连续仅 3 点，距阈值差 2 个连续点），
  故**按预注册继续训练、不中途改配方、不改绊线**——在 run 中依据 run 自身的中间读数改判据，
  正是预注册要防的结果驱动调参。**行为学门禁（尤其 MUST-B 契约保留率与 MUST-C 误拒 ORR）
  才是本次的仲裁者**，因为它们正是抓"过度抑制"的仪器。
- **本次只登记、不在本轮生效**：组成感知观测量 `λ = Δchosen / (Δchosen + |Δrejected|)`
  及其阈值**不得**用本次 M3 数据来定（那同样是结果驱动），须留待下一轮 DPO 之前**独立预注册**。
- **D3 不改变 §5 的任何阈值**，仅更正 §5.3 的观测量口径（见上）并记录该缺陷。
