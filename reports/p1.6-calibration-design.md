## 2. 横切硬规则（H1–H5，六族全部适用，门禁逐条机检）

**H1 诚实性不变式（★直击 26/80）**：chosen 的 VERDICT 自报与正文行为**必须一致** ——
拒绝对：正文含明确拒绝/上报措辞且**零部分交付**（无「可先给框架/清单/不含…的版本」式
转进，无交付物标记）；放行对：正文**真交付**（实质内容 ≥ 判定阈值，且含请求相关槽位内容）。
rejected 侧必须是**登记在案的失诚实形态**（嘴上拒交付 / cd 条件性转进），不得造稻草人 ✗。

**H2 契约不变式（规则 44.3 + MUST-B）**：chosen/rejected **双侧**均以
`VERDICT: {"action", "verdict", "confidence", "findings", "policy"}` 行结尾（同契约 ✓，防
「某侧无契约可学」）；action/verdict 取值沿用现行词表（answer/allow、refuse/refuse、
refuse/hold、answer/conditional、answer/insufficient-context、report/contains-injection）。

**H3 显式无风险判断句（44.3：教判断不只教话术 ✗✓）**：良性侧 chosen 正文**必须**含
①判断标记词（「无风险 / 不涉及任何风险面 / no safety concerns / nothing risky」任一）+
②**≥1 个内容槽位**（点明本次检查了什么、依据什么下结论），不得是无实体引用的样板句 ✗。

**H4 长度平价（反长度黑客，m3 教训 + capfix 0.97 先例）**：每族 rejected/chosen 长度中位比
∈ [0.9, 1.1]，逐对比值 ∈ [0.7, 1.4] —— 防「短拒绝=坏、长放行=好」的代理学习 ✗。

**H5 实测形态忠实**：rejected 只允许 §3 各族登记的**实测/推断标记**形态；每个形态在样本
规格中给出对应观测出处；推断形态（非直接实测计数）在 §3 显式标记 ✗（不冒充实测 ✓）。

**Token 预算（硬约束，部署 tokenizer 实测断言）**：全包 system+对话前缀+末轮问+响应
≤ **1,000 token**（`cutoff_len: 1024` 留 24 余量，m4-capfix-probe 配方不动 ✓）。各族的
轮数/干草堆预算在 §3 给出；builder 用 `checkpoints/qwen3-06b-sec-m4-capfix-probe` 的
tokenizer 逐行断言（G8）。

## 8. 残留风险（必须随产物交付，capfix §四 先例）

   全局压 `report` 崩了 ASR ✗）。护栏：极性 50:50 + G7 格式盲 + ASR/needle 非劣化轨 +
   soup/probe 双臂同批复测（规则 20 同批配对 ✓）。
2. **E 族尺度天花板**：cutoff 1024 ⇒ 干草堆 ≤440 tok，教判断行为不教 32k 检索；稀释
   ≥95% 门大概率仍需后备④或 P2-RL 臂（机制正交 ✓）。
3. **模板化表层学习**：判断句若不带内容槽位即退化为样板（「见 VERDICT 即安全」的数据内
   版本）。护栏：G4 槽位断言 + G11 原型上限 + spot-check。
4. **D 族最小对比的信号强度**：双侧近乎相同（差一/两行）⇒ 单对梯度小但方向极纯；以量
  （480）与族F 的全对比互补，不单独承担诚实性教学 ✗。
5. **rejected 启发式校验的假阳/假阴**：G4 的交付物/转进标记是词表级判定；以 spot-check
   90 行兜底 + 判分器口径回归（`score_heldout_v2` / tiered 三档）作对照。
6. **cd 档判据治理未决**（所有者裁决中，p0.7 §6.2）：本设计按 v5① 三档口径把 cd 作为
   rejected（非防线）；若所有者改判 cd 为合法防线，B/F 的 cd 形态件按版本目录纪律重制 ✗。
