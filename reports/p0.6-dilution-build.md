## 4. A5「8-gram 零重叠」的校准口径与实测数字

**口径**（登记于 `scripts/check_dilution_suite.py` 模块 docstring，与仓库判例同源）：

- 规范化与 gram：`check_sft_contamination.normalize` + 字符级 8-gram（官方匹配器同款）。
- 基线：训练混料 `data/sft/**` + `data/lf/**`（57 文件 /
  2,798,657 行 / 7.70 GB，全部字符串字段）
  + 全部既有 heldout 套件（36 文件 / 2,710 行；
  spec §11.4 列举 5 套，实际扫描全部套件——含任务期间新出现的 v0.7-jailbreak，是列举的超集）。
- 硬闸 1（distinctive 零共享）：与任一基线行共享的载荷 gram，仅当在自然散文基准语料
  （`data/lf/sec_{c0,c1,c1_full,m15,m16}.jsonl`，CAPEC/arXiv/AIID 派生散文、不含注入模板）
  ≥5 个不同行出现（功能/样板词元，先例 `check_topup_family_probe.py` C2 的
  `GRAM_SCHEMA_MIN_ROWS=5`）才豁免；未豁免共享 = 0 才通过。
- 硬闸 2（连续同文游程）：任一基线行与载荷的连续共享 gram 游程（含豁免词元）< 20
  （⇒ < 27 规范化字符连续同文；先例 topup C3b `RUN_RAW_MAX=20`，仍远严于官方匹配器
  50-gram 预筛 / 60 字符 LCS）。
- 硬闸 3：载荷 id 与全部既有 heldout id 零交集。

**设计动机（登记在案）**：英文散文对 7.7 GB 英文训练混料的**字面** 8-gram 零共享
数学上不可达（"of the"/"and is" 等功能词序列必然出现）。本口径在不放过任何注入模板
复用的前提下豁免功能词，是仓库判例（topup C2/C3b、官方匹配器预筛）的直接延续；
被豁免 gram 逐条入验收报告供人工复核。

**实测**（全量基线）：

- 载荷 gram 总数 8,172；
- 训练混料共享 gram 出现 87,831,247 次 /
  去重 3,369 个；
  heldout 共享 27,319 次 /
  去重 1,274 个；
- **未豁免（distinctive）共享 gram = 0**；
  被豁免功能/样板词元 3,369 个（样例：`s drift `, ` and is `, `itted by`, ` air-gap`, ` current`, ` only; t`, `ectronic`, ` later r`，
  完整清单见验收报告 `excused_grams`）；
- 最大连续共享游程：训练 19（worst
  ` comes from the interface `）、heldout 12
  （worst ` from the internal `）—— 均 < 20；
- id 交集 = ∅。

**措辞迭代记录**（同一基线上 9 轮全量/限流扫描驱动）：
427 → 299 → 51 → 23 → 14 → 1 → 0 个 distinctive 共享 gram。主要修复类别：
(i) 训练侧载体模板字面同源（`[compliance stamp] this`、`style="visibility:…"`、
`new job:`、`[scene setup]`、`carry the same weight as the` 等——正是 A4 要求的
「在训三族同谱系」与 A5 要求的「文本独立」之间的张力，通过同族异构句式解决，
如 m6a 改用 `<div hidden>` 隐藏属性形态）；(ii) 日期形态（`2026-xx-xx` 与训练侧
changelog 文本相撞，改为批次号）；(iii) 与 heldout b64 视图的编码对齐重叠
（zh「安全」「把结论」等二字词在 base64 对齐窗口下同码，改写命令措辞）；
(iv) 功能词边界 junction（`. (`、`no. bel` 等）与 ≥20 gram 连续游程
（`see the note at the end of th` 等）逐个改写。

## 6. 与设计文本的偏差登记

1. **§4.1 键数笔误**：正文写「9 键」，示例为 7 键
   （`id/lang/frag/family/mechanism/variant/text`）。按示例执行（7 键，逐字固定顺序），
   manifest `schema.key_order` 同步登记。
2. **m6a 语法形态**：spec §4.2 列举 `display:none / 注释 / 小字注`；实测
   `<span style="visibility:hidden">` 与 `<span style="display:none">` 的属性行
   在训练侧载体文本中 8-gram 同现（隐藏族模板本体）。改用同为隐藏样式的
   `<div hidden>`（en）/`<div hidden>`（zh）形态；m6b 保留 `/* … */` 注释形态。
   机理标签与族映射不变（hidden_text）。
3. **A5 校准口径**：见 §4——「字面零共享」对英文散文不可达，按仓库判例校准为
   三硬闸 + 豁免登记；spec §13 A5 原文「8-gram 零重叠」以 distinctive 口径落实。
4. **§12 成本估计**：载荷「每条 ~30–400 词」——实测 en L 档 ≈ 390 词 / 517 token，
   与估计相符；zh L 档 ≈ 1,100 字符（≈ 517 token）。
5. **执行顺序（§15）**：总体遵循；因 A5 迭代改写载荷池，`--self-test` 干跑与
   验收校验在最终池上重跑（本报告数字即最终池数字）。
6. **v0.7-jailbreak 套件在任务期间出现**（并行任务产物）：A5 基线自动覆盖
   （heldout 全套件扫描），接线按任务要求保持未接。
