## 4. G4 双向量 + span 承重件专章

**G4 双向量框架**（F-5）：G4 失败 = **is_ood 塌陷**（4.6% vs v1-3 9.2%，LoRA 吸收 OOD 分离度——几何级）× **span 强带旁路**（310/500 OOD 行 T4 旗 ≈ 98% of fails——语境盲 token 分类器骑强带 = default-pass 违反向量）。两向量独立成因而症状合并；修复必须双管（OOD 头 + span 语境化）。

**span 通道三平面张力全景**（F-6 + 从属化计数 77cc864/433c565）：
- **dev 面**：TP:FP = 1:30（span 通道在 dev 上 FP 主导）
- **heldout 面**：9% TP 承重（27/300 T4 正例 span-only 依赖，doc-quiet）+ 2.3% benign FP 份额（84/3,600）——**承重件**（从属化 NO-GO 的金标依据：G1 代价 9% 破 95 地板 + G2 收益仅 49% 份额，双重否定）
- **OOD 面**：62% OOD 行 span-only flag（default-pass 违反向量）

语境盲 token 提取**承载 doc 头看不见的真实检测**（defense-in-depth 实证）同时**产生它无法避免的 lawful-context FP**——这是结构张力而非缺陷，修复 = 语境化（context-gate），非切除。
