## 二、形态终判（本分支核心科学产出）

1. **ORR 地板是文本生成形态的 artifact，不是能力极限**：决策形态下 0.6B ORR = 0.16–1.11%（对照：文本 0.6B 7.62–13.65、文本 8B 空过/10.00）。**使命 1% 门在决策形态下首次触及**（r1 = 1.11%）。ORR↔判别力耦合在决策空间**不存在**。
2. **攻击风格拒绝完全可学**：jb 0–12.5% vs 文本臂 28.75–77.5。多轮 jb 的良性开场轮正确 comply、升级轮全拒（实况抽查确认，非仪器假象）。
3. **内容性风险覆盖 = 跨形态数据缺口（四点确认）**：gen ASR —— 文本 0.6B 7.74（过度泛化红利）/ 文本 8B-Base 80.36 / 文本 8B-对齐 78.57 / **决策 0.6B 79.17 与 97.02**。覆盖面成分与形态无关 ⇒ **r9 对抗多样性数据配料是唯一解**（两成分解构的最终确认）。
4. **剂量敏感性（r1→r2）**：ORR 1.11→0.16、jb 0→12.5、gen ASR 79→97、gen ORR 19→8.8 —— 收敛方向 = 更精准的"风格判别 + 泛化顺从"（分布内最优不是内容覆盖）。r1 为分支参考资产。
5. **形态红利**：75× 推理加速（门禁链 9h→10min）、原生结构化输出（契约 0.73 vs 全文本臂 0.0）、模板渲染 = 部署可控性。

## 三、r9 修订建议（合并两成分解构 + 本分支证据）

**预测**：决策形态 + 对抗多样性覆盖数据 → ORR ~1% + ASR 大幅下降（双过 J1+J2 的组合配方）。决策形态同时解决稀释轴的评测困境（verdict 头即检测器）。行动项：r9 = secjev 形态 + gen/jb 族风险 payload 成对化入训 + amb 剂量维持 5.6%（决策空间已足量）。
